Your team's repo

python3 setup_agent.py "<Team> Table Plot" ../../<team>-agent
cd ../../<team>-agent         # no ~ in the path above
git init -b main && git add . && git status   # no .env!
git commit -m "Scaffold the agent"
gh repo create <team>-agent --private --source=. --push

# teammates
gh repo fork <owner>/<team>-agent --clone
cd <team>-agent; git config pull.rebase true
cd ~/prometheus/prometheus_core/agent-template
python3 setup_agent.py --env-only ../../<team>-agent   # YOUR .env

No gh? brew install gh, or the release binary in ~/.local/bin, then gh auth login. Or use the web UI.

Git, every piece of work

git fetch upstream
git switch -c feature/<team>-<what> upstream/main
git commit -m "Imperative subject under 72 chars"
git pull --rebase upstream main
git push -u origin HEAD          # after a rebase:
git push --force-with-lease      #   your branch only
gh pr create --repo <owner>/<team>-agent --base main

Never commit .env. Every merged PR needs an approval: the owner reviews teammates, a teammate reviews the owner (gate #7).

Flavors: small, medium, large, vision, embedding. Provider in your agent's .env: LLM_CONFIG_PROFILE (required: anthropic, openai, genesis, ollama, amsc, anl_asksage, inl_hpc, inl_litellm), plus that provider's key in LLM_API_KEY (the same variable for every profile). setup_agent.py copies both from platform/.env.

Long work

  • Blocking code: await asyncio.to_thread(fn, …)
  • With progress: a PrometheusWorker run via await self.run_worker(worker, context, event_queue)
  • Minutes or more: await self.declare_long_running(context, event_queue, estimate_seconds=…)

Packaging

  • uv add pandas matplotlib, then commit pyproject.toml and uv.lock; never prometheus_api
  • MPLBACKEND=Agg; a COPY line in the Dockerfile per extra module
  • uv run pytest and uv run ruff check . must pass (first uv pip install -e ~/prometheus/prometheus_core/sdk)
