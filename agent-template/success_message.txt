Run with Docker (integration testing / deployment):
  # Set PROMETHEUS_API_BASE_IMAGE_HASH in .env first (defaults to `latest`)
  # No registry access? Build the base image locally first:
  #   make -C <monorepo>/platform base-image
  # then set LOCAL_SDK=true in .env (setup does this when the platform uses it)
  make up-fg

By default, make joins the platform Docker network. To expose the agent port,
set both EXTERNAL_AGENT_HOST and EXTERNAL_AGENT_PORT before running make.
